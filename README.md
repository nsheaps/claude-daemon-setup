# claude-daemon-setup

Turns a mac into a temporary [Claude Code Remote Control](https://code.claude.com/docs/en/remote-control) host via a Homebrew service, with an isolated config root so it never touches your interactive `~/.claude` setup.

Status: early scaffolding — see [`docs/specs/draft/overview.md`](docs/specs/draft/overview.md) for the design and build order, and [`docs/research/`](docs/research/) for the pattern research this scaffold is grounded in.
