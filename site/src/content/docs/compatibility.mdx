## Known limitations

- **`CLAUDE_CONFIG_DIR` does not isolate `CLAUDE.md` memory discovery.**
  Claude Code recurses for `CLAUDE.md` upward from the working directory
  regardless of `CLAUDE_CONFIG_DIR`. This is a known, accepted limitation in
  the MVP, not a bug &mdash; see `docs/specs/draft/config-isolation.md`.
- **No rollback on a bad auto-update.** If a new binary fails its smoke
  check, the daemon logs and continues running the old process; there is no
  automatic revert of the installed binary in the MVP &mdash; see
  `docs/specs/draft/auto-update.md`.
- **Per-agent `gh`/`git` isolation is untested.** Whether Claude Code honors
  `GIT_AUTHOR_*` env vars or requires an explicit `--author` flag has not
  been verified yet.
